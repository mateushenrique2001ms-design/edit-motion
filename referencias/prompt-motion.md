# Referência: Prompt Motion (prompt-motion.com)

**Origem**: `https://prompt-motion.com/`  
**Descrição**: Coleção de referência de vídeos em Motion Graphics, animações programáticas e vídeos gerados via código (Remotion / HyperFrames / GSAP / Claude), com prompts e skills aplicados por motion designers.

## Categorias e Padrões de Referência Observados:
1. **Kinetic Typography & Lettering**:
   - Revelações palavra por palavra sincronizadas com marcadores de áudio/fala.
   - Tipografia limpa, caixas altas para palavras-chave, tracking animado.
2. **Layouts Dinâmicos**:
   - Câmera cheia (Full Screen) alternando com tela dividida (Split Screen).
   - Cartões flutuantes (Cards / B-Roll / Peças de UI) entrando com easing suave.
3. **Efeitos Visuais Sutis**:
   - Gradientes mesh / noise / grain sutil no fundo.
   - Vignette leve para direcionar o foco visual.
   - Sombra e elevação de camadas (depth/z-index).
4. **Áudio & SFX**:
   - Swoosh, pop, type e riser sincronizados nos cortes e entradas de elementos.
   - Nível de áudio em −14 LUFS com picos controlados.

## Aplicação no Workflow do Editor:
- Utilizar estes padrões nos scripts de geração de `beats.js` e composições Remotion / HyperFrames.
- As skills instaladas (`motion-graphics-studio`, `gsap-skills`, `remotion-best-practices`, `hyperframes`) cobrem diretamente os blocos e componentes vistos no Prompt Motion.
