# Vídeos de Referência

Coloque nesta pasta os vídeos que você quer usar como referência antes de iniciar uma edição.

### O que colocar aqui:
- **Vídeos MP4/MOV**: Reels, TikToks, shorts ou vídeos longos com o estilo visual, ritmo de corte ou motion graphics que você deseja replicar.
- **Notas de Estilo (opcional)**: Você pode criar um arquivo de texto ou markdown ao lado do vídeo (ex: `ref-01.txt`) apontando:
  - O que você mais gostou (ex: "estilo da legenda", "ritmo rápido dos cortes", "transição aos 00:05", "paleta de cores").
  - Trilha sonora / efeitos sonoros de referência.

### Acesso rápido:
- Caminho: `c:\Users\cobain\EDITOR AUTOMÁTICO\referencias` (ou `REFERÊNCIAS`)
